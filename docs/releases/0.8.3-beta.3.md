# 0.8.3-beta.3

修复 Desktop transport 在停止、断连或卸载时未传入官方 `Agent.cancel(cause)` 参数的问题。DSH `0.2.2-rc.1` 的收尾路径会因此写出 `turn/end.reason:null`，使聊天视图读取 `.kind` 时崩溃；停止和断连现在传 `{kind:'user'}`，卸载传 `{kind:'disposed'}`，且卸载关闭 socket 不再触发第二次取消。

新增真实 Unix socket Host 回归测试，覆盖停止、断连、卸载以及合法终态。官方缺陷的同类讨论见 [#9699](https://github.com/deepseek-ai/deepseek-harness/discussions/9699) 和 [#11899](https://github.com/deepseek-ai/deepseek-harness/discussions/11899)。本版本阻止 bridge 继续生成该坏事件；已有日志需要先备份、退出 Desktop 后单独修复，不能把缺失原因自动视为成功。

安装：`npm install -g @bwlfhu/lark-channel-bridge@0.8.3-beta.3`，并更新 Desktop profile 中的同名 Host 插件后重开应用。详见 [Desktop runbook](../runbooks/dsh-desktop.md)。使用 npm `beta` 标签，稳定版 `latest` 不变。
