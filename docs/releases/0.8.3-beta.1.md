# 0.8.3-beta.1

这是完成提醒功能的首个 beta 预发布版，使用标准 SemVer 预发布格式 `0.8.3-beta.1`。

群聊或话题中，同一位真人明确 @ 当前 bot 发起任务后，若 agent 正常完成且运行至少 30 秒，bridge 会在原回复送达后使用当前 agent/model 单独判断是否值得提醒。判定为值得回看时，bridge 会在原群/话题另发一条带提问人原生 @ 的消息。

不会提醒快速回复、bot 发起、混合发起人、reaction/direct-correction 运行，以及失败、中断、超时或没有可供检查的最终答案。LLM 输出必须是仅含布尔 `notify` 字段的 JSON；超时、工具调用、错误或格式不符均按“不提醒”处理。提问人目标由入站真人 sender 固定，模型不能选择提及对象或生成提醒正文。

Judge 使用新的一次性运行，不恢复原会话。Claude judge 禁用工具并关闭会话持久化；Codex judge 使用 ephemeral、只读 sandbox 和临时工作目录。DSH 后端暂不运行 judge，因为当前 CLI 没有已验证的禁用工具选项；只读模式不能作为无副作用保证。Codex 和 Claude judge 均不会修改原任务历史。

```sh
npm install -g @bwlfhu/lark-channel-bridge@0.8.3-beta.1
```

此 beta 暂无配置开关，提醒判断默认启用。实际发出的提醒是独立飞书消息；若发送失败，bridge 只记录不含消息正文的错误类型，不影响已完成的任务回复。
