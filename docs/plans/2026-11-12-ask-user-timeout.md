# ask_user 超时采用推荐方案

用户要求：不因等待用户选择超时而终止任务，超时时按推荐选项继续。

- Codex/Claude 共用 schema 增加 option.recommended，单选最多一个、多选可多个；兼容旧推荐后缀。
- 问题卡明确显示推荐方案及 10 分钟自动选择规则。
- Broker 超时重新验证活跃 run、route lease 和卡片送达；仅补齐未回答题目，保留人工回答。
- 回传 answered，自动答案逐项标记 source=timeout_recommendation；终态卡片及日志明确说明自动选择。
- 取消/停止/断连不会当作超时；无推荐项的选择和纯文字答案不凭空构造。
- 不重放旧任务，不调整其他工具权限，不修改已发布 beta.4。以 beta.5 发布并在空闲时切换本机三个 profile。

验证：先用回归用例证明旧实现失败；覆盖部分回答、多选、推荐歧义、迟到点击、取消、断连和 run/lease 失效。真实 Codex/Claude 使用打包 MCP 入口，在无模拟点击的情况下验证超时返回和任务继续；测试缩短 Broker 时限，生产仍为 10 分钟。另运行全量回归、typecheck、build、制品干净安装及发布完整性校验。
