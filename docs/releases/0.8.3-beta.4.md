# 0.8.3-beta.4

Codex 与 Claude 新增 MCP `ask_user`：Agent 可提交结构化问题，在飞书发送可点击的选项/多选/文字表单，等待提问人回答，再继续当前任务。回答不经过普通聊天消息队列。

- 原生卡片包含补充回答、取消和有效期；超时/中止不默认为同意。
- 校验当前用户访问权限、原提问人、原聊天/话题、卡片、问题、有效期和活跃 run；重复提交只消费一次。
- 取消、任务结束、断开和重启清理待答状态，不自动重放任务。
- Codex 转换 MCP 工具执行事件，等待期间不触发普通输出空闲超时；专用 MCP 工具使用独立允许规则，保持命令审批策略不变。
- Claude 使用临时 MCP 配置；完成提醒 judge 不获得问答工具；DSH Desktop 机制保持兼容。
- macOS 的长 profile 路径使用私有短 socket 路径。

本版本为 beta，使用 `npm install -g @bwlfhu/lark-channel-bridge@beta`。详见 [使用与边界](../runbooks/ask-user.md)。
