# 0.8.3-beta.5

Codex/Claude 的 `ask_user` 在等待 10 分钟无人回答后，会自动采用明确标记的推荐选项并继续原任务。问题卡事先显示推荐方案和超时规则；已回答题目保持不变，自动答案带 `source: timeout_recommendation`，终态卡片和日志也标明自动选择。

- 选项支持 `recommended: true`；单选最多一个推荐，多选可多个。兼容 `（推荐）` / `(Recommended)` 后缀。
- 超时重新校验活跃运行、原路由和问题卡送达；迟到点击不会覆盖自动答案。
- 主动取消、停止、断连等不当作超时同意；纯文字或没有明确推荐项的题目无法自动补全。
- 不改变命令权限/审批机制；DeepSeek Desktop 沿用现有原生问答机制。

安装：`npm install -g @bwlfhu/lark-channel-bridge@0.8.3-beta.5`。
