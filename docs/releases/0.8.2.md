# 0.8.2

工具展示新增三种模式：`full`（兼容默认）、`live-only`（仅运行时显示）和 `hidden`（隐藏）。升级后在对应 profile 的 `/config` 或 Web 控制台选择“仅运行时显示”，应在新一轮任务开始前设置。

`live-only` 在底部显示最新运行命令，并显示其余并发工具数量。工具完成后立即移除状态，最终消息保留 AI 正文、已有思考内容和必要的失败、中断、超时提示。工具输出仍保留在内部状态和诊断中。

旧 `showToolCalls` 配置和旧表单/API 请求继续兼容；有效的显式 `toolDisplayMode` 优先。卡片、Markdown、最终回复和异常回退遵循同一策略。

## 行为边界

- COT 是持久事件记录。任务以 `live-only` 开始时改用可更新卡片；`hidden` 不发布工具事件；`full` 保持原行为。自动化已覆盖该分支，本次没有切换运行中 profile 做 COT 现场验收。
- 从 `full` 中途切换模式无法清除已定稿 Markdown 分段或已发布 COT 的历史内容。下一轮开始前选择 `live-only` 可获得完整的无工具历史展示。
- 纯文本且未开启 COT 时仍在任务结束后一次发送，不提供过程状态。
- 发布不修改现有 profile，也不安装或重启当前 daemon。部署后的原生模型新建/续接和 profile 配置验收属于独立升级步骤。
