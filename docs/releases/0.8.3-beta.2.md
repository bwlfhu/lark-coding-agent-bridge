# 0.8.3-beta.2

新增可选 DSH Desktop transport：飞书任务连接正在运行的官方 Electron，在桌面中创建和续接 PTC 会话，并使用官方 Computer Use。新增代码集中于桥接适配器和随包发布的 Desktop Host 插件；无需修改官方应用或安装社区 CUA 驱动。原有 CLI transport 继续作为默认配置。

支持桌面执行事件、停止、通过原飞书 channel 处理应用授权/提问，以及任务完成后回传工具截图。私有 socket、路由和卡片绑定保护交互；持久化请求收据防止断流或重启后重复执行。首次迁移原 headless session 会创建映射的新 Desktop 会话，旧日志保留，但不自动导入对话。原生飞书图片输入暂不支持。

包含 beta.1 的完成提醒功能。DSH judge 继续停用，Codex/Claude 提醒行为不变。Desktop 与模型由官方应用配置管理；模型需实际支持图像，macOS 需授予 DSH Computer Use 辅助功能、屏幕录制权限。

安装：`npm install -g @bwlfhu/lark-channel-bridge@0.8.3-beta.2`。完整安装、验收和回滚步骤见 [Desktop runbook](../runbooks/dsh-desktop.md)。此为 beta 版，发布使用 npm `beta` 标签，稳定版 `latest` 保持不变。
